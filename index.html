LebGames · Player support

Request account deletion

Request deletion of your Banana Run account and associated game data, even if you can no longer open the game.

Send a deletion request

  1. If you can open Banana Run, go to Account Settings and copy your Support Code.
  2. Use the button below to email our support team. Include your Support Code if available and request deletion of your Banana Run account.
  3. We may contact you to verify account ownership before processing the request.
Request deletion by email

Or email support.lebgames@gmail.com directly.

Never send passwords or sign-in credentials. A Support Code can help locate an account but does not by itself prove ownership.

What data is covered?

Deletion requests cover the Banana Run account and its associated game data, where present:

  • Unity Authentication account identity associated with Banana Run
  • Cloud-saved progress and game settings
  • Nickname, profile information, and uploaded profile picture
  • Friend relationships and leaderboard records

Some information may be retained if required by applicable law or for legitimate security and compliance reasons. If this applies, we will explain the data retained and applicable retention period when responding to your request.

Delete your account in the game

If the feature is available in your installed version, open Banana Run's Account Settings, select Delete Account, and follow the confirmation steps. If the option is unavailable or fails, you can still request deletion using the email option above.
